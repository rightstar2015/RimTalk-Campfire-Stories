# Dedicated ritual icon — 0.2.1

Asset: Textures/UI/Icons/Rituals/CS_CampfireStories.png

Generated with imagegen for the war song cultural ritual. Amber/orange flame, golden center and crossed brown logs, with bold dark outlines and a real transparent background. The selected asset is preserved directly as generated. White silhouette drafts were rejected because their alpha edges were unsuitable for the game.

Both the precept definition and ritual pattern point to the dedicated texture. On game load, old Campfire Stories rituals using the original festival icon are upgraded; other custom icon overrides are retained.
