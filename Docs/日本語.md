RimTalk - Campfire Stories（焚き火の物語）は、1～3 人の入植者が標準の焚き火を囲み、聞き手の方を向いて日々の出来事を語り合う Mod です。日常、戦い、人間関係、誰かを偲ぶ話など、話題は自由です。

## 本来の体験に必要な Mod

以下の Mod がなくても文化儀式を行えますが、私が当初作りたかった体験にはなりません。

- [RimTalk](https://steamcommunity.com/workshop/filedetails/?id=3551203752)：有効にすると「前に出る → 話をする」という一連の会話を実現できます。本体のモデルと API 設定をそのまま使います。
- [RimTalk - Expand Memory](https://steamcommunity.com/sharedfiles/filedetails/?id=3608181242)：有効にすると、語り手本人の拡張記憶からランダムに話題を選べます。

## 仕組み

必要環境は RimWorld 1.6 と Ideology です。RimTalk がなくても通常の儀式とその結果を得られます。RimTalk のみの場合は語り手自身の会話履歴を使い、Expand Memory もある場合は拡張記憶に切り替わります。API キーの再入力は不要です。独自の特殊な交流行動や明示的な記憶の書き戻しは追加しません。

## 使い方

1. イデオロギーに「武勲の歌」を追加します。
2. 焚き火を建てて点火し、焚き火を選択して儀式を始めます。
3. 参加者と語り手を選んで開始します。語り手は最大 3 人まで指定でき、空欄なら自動で選ばれます。

## 設定

Mod 設定の「焚き火の物語」で、自動選出する語り手の人数、応答人数、一言あたりの文字数、会話の雰囲気を調整できます。話し方や話題を変えたい場合は、専用プロンプトを編集してください。

会話には RimTalk のモデルと API 設定を使います。API キーを別途入力する必要はありません。
