RimTalk - Campfire Stories brings one to three colonists together around a native campfire to face their audience and share small moments from their lives. Everyday life, battles, relationships and remembrance are all welcome topics.

[h2]Mods for the intended experience[/h2]

You can perform the cultural ritual without these mods, but it will lack the experience I originally wanted to create.

- [url=https://steamcommunity.com/workshop/filedetails/?id=3551203752]RimTalk[/url]: enables the full “take the floor → give a speech” dialogue sequence, using RimTalk's existing model and API settings.
- [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3608181242]RimTalk - Expand Memory[/url]: enables random selection from each storyteller's own expanded memories.

[h2]How it works[/h2]

Requires RimWorld 1.6 and Ideology. Without RimTalk, the ordinary ritual and its standard outcomes still work. With RimTalk, speakers generate dialogue from their own built-in conversation history; adding Expand Memory switches to their expanded memories. No second API key setup is needed. No special interaction actions or explicit memory writeback are added.

[h2]Getting started[/h2]

1. Add [b]war song[/b] to your ideology.
2. Build and light a campfire, then select it to start the ritual.
3. Choose participants and storytellers, then begin. You can nominate up to three storytellers or leave the role empty for automatic selection.

[h2]Settings[/h2]

Open [b]Campfire Stories[/b] in the mod settings to adjust the number of automatically selected storytellers, replying listeners, characters per line and dialogue style. Edit the dedicated prompt to change the tone or topics.

Dialogue uses RimTalk's model and API settings. No separate API key is needed.
