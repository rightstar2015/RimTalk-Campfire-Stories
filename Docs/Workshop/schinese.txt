「我只是想看我家可爱小米讲话，所以才做了这个模组。」

[h2]需求 Mod[/h2]

不使用以下模组也能进行此文化仪式，但是没有我当初想呈现的效果。

- [url=https://steamcommunity.com/workshop/filedetails/?id=3551203752]RimTalk[/url]：启用这个模组才能实现“上台 → 演讲”的完整对话环节，沿用本体的模型及 API 设置。
- [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3608181242]RimTalk - Expand Memory[/url]：启用之后就能抽取讲述者自己的随机记忆。

[h2]篝火的故事[/h2]

让 1～3 名殖民者围坐原生篝火，轮流面向人群，分享生活中的片刻。日常、战斗、人际与纪念都能成为话题。

基本需求为 RimWorld 1.6 和 Ideology。没有 RimTalk 时仍可完成普通文化仪式及获得一般仪式结果；安装 RimTalk 后会生成文字对话，仅有本体时使用讲述者自己的内置对话历史，同时安装 Expand Memory 时改用扩展记忆。无需再次输入 API Key，不增加特殊互动或主动记忆写回。

[h2]使用方式[/h2]

1. 在文化中添加“战功歌”。
2. 建造并点燃篝火，点击篝火开始仪式。
3. 选好参与者和讲述者后开始。最多可指定三位讲述者；不指定则自动选择。

[h2]设置[/h2]

在模组设置中打开“篝火的故事”，可调整自动挑选的讲述者人数、接话人数、每句字数及对话风格。想改变故事的语气或话题，可以编辑专属 Prompt。

对话使用 RimTalk 的模型和 API 设置，不用另外填写密钥。
