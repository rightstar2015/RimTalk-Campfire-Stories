RimTalk - Campfire Stories(모닥불 이야기)는 1~3명의 정착민이 기본 모닥불 주위에 모여 청중을 바라보며 삶의 작은 순간들을 나누는 모드입니다. 일상, 전투, 인간관계, 누군가를 추억하는 이야기까지 어떤 주제든 좋습니다.

[h2]의도한 경험을 위한 모드[/h2]

아래 모드 없이도 문화 의식을 진행할 수 있지만, 제가 처음 만들고 싶었던 경험을 온전히 즐기려면 이 모드들이 필요합니다.

- [url=https://steamcommunity.com/workshop/filedetails/?id=3551203752]RimTalk[/url]: 본체의 모델과 API 설정을 사용하여 “앞으로 나가기 → 이야기하기”로 이어지는 대화 과정을 구현합니다.
- [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3608181242]RimTalk - Expand Memory[/url]: 각 이야기꾼 자신의 확장 기억에서 무작위로 이야깃거리를 선택합니다.

[h2]작동 방식[/h2]

RimWorld 1.6과 Ideology가 필요합니다. RimTalk이 없어도 일반 의식과 그에 따른 결과는 정상적으로 작동합니다. RimTalk만 있으면 이야기꾼 자신의 내장 대화 기록을 사용하고, Expand Memory도 있으면 확장 기억을 사용합니다. API 키를 따로 설정할 필요는 없습니다. 별도의 특수 상호작용이나 기억을 직접 기록하는 기능은 추가하지 않습니다.

[h2]사용 방법[/h2]

1. 이념에 [b]무훈의 노래[/b]를 추가합니다.
2. 모닥불을 설치하고 불을 붙인 뒤, 모닥불을 선택하여 의식을 시작합니다.
3. 참가자와 이야기꾼을 선택하고 시작합니다. 이야기꾼은 최대 세 명까지 지정할 수 있으며, 역할을 비워 두면 자동으로 선택됩니다.

[h2]설정[/h2]

모드 설정에서 [b]모닥불 이야기[/b]를 열면 자동으로 선택할 이야기꾼 수, 대답할 청중 수, 대사당 글자 수와 대화 분위기를 조절할 수 있습니다. 말투나 주제를 바꾸려면 전용 프롬프트를 편집하세요.

대화에는 RimTalk의 모델과 API 설정을 사용합니다. API 키를 별도로 입력할 필요는 없습니다.
