RimTalk - Campfire Stories（焚き火の物語）は、1～3 人の入植者が標準の焚き火を囲み、聞き手の方を向いて日々の出来事を語り合う Mod です。日常、戦い、人間関係、誰かを偲ぶ話など、話題は自由です。

[h2]本来の体験に必要な Mod[/h2]

以下の Mod がなくても文化儀式を行えますが、私が当初作りたかった体験にはなりません。

- [url=https://steamcommunity.com/workshop/filedetails/?id=3551203752]RimTalk[/url]：有効にすると「前に出る → 話をする」という一連の会話を実現できます。本体のモデルと API 設定をそのまま使います。
- [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3608181242]RimTalk - Expand Memory[/url]：有効にすると、語り手本人の拡張記憶からランダムに話題を選べます。

[h2]仕組み[/h2]

必要環境は RimWorld 1.6 と Ideology です。RimTalk がなくても通常の儀式とその結果を得られます。RimTalk のみの場合は語り手自身の会話履歴を使い、Expand Memory もある場合は拡張記憶に切り替わります。API キーの再入力は不要です。独自の特殊な交流行動や明示的な記憶の書き戻しは追加しません。

[h2]使い方[/h2]

1. イデオロギーに「武勲の歌」を追加し、標準の焚き火を建てて点火します。
2. 参加者と最大 3 人の語り手を選びます。語り手を指定しなければ 1～3 人を自動選出します。
3. 儀式を始めると、語り手が交代で聞き手の方を向きます。AI が利用できる場合、語り手の話、聞き手の応答、短い締めくくりが続きます。

語り手の人数、応答人数、文字数、待機上限、専用プロンプトを設定できます。AI が利用できなくても通常の儀式は続きます。RimTalk と Expand Memory がそれぞれ必要とする前提 Mod を導入し、本 Mod をその後に読み込んでください。

[h2]動作確認と仕様[/h2]

実際の API による会話、セーブとロードの一連の動作、カスタム種族、多数の Mod を導入した環境、語り手の向きは実際のプレイで確認済みで、正常に動作しています。

RimTalk の会話履歴は本体が管理します。再起動後に履歴が空になるのは通常の動作です。記憶がない場合は現在の話題を使います。AI の内容や文字数はモデルによって変わります。
