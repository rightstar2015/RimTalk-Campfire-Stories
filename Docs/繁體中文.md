## 需求 Mod

不使用以下模組也能進行此文化儀式，但是沒有我當初想呈現的效果。

- [RimTalk](https://steamcommunity.com/workshop/filedetails/?id=3551203752)：啟用這個模組才能實現「上台 → 演講」的完整對話環節，沿用本體的模型及 API 設定。
- [RimTalk - Expand Memory](https://steamcommunity.com/sharedfiles/filedetails/?id=3608181242)：啟用之後就能抽取講述者自己的隨機記憶。

## 篝火的故事

讓 1～3 名殖民者圍坐原生篝火，輪流面向人群，分享生活中的片刻。日常、戰鬥、人際與紀念都能成為話題。

基本需求為 RimWorld 1.6 與 Ideology。沒有 RimTalk 時仍可完成普通文化儀式及取得一般儀式結果；安裝 RimTalk 後會生成文字對話，僅有本體時使用講述者自己的內建對話歷史，同時安裝 Expand Memory 時改用擴展記憶。無需再次輸入 API Key，不增加特殊互動或主動記憶寫回。

## 使用方式

1. 在文化中加入「戰功歌」，建造並點燃原生篝火。
2. 選擇參與者，指定最多三位講述者；留空則自動選擇 1～3 人。
3. 開始儀式，講述者輪流上前並面向聽眾。AI 可用時由講述者開場、聽眾接話，再簡短收尾。

設定可調整講述者人數、接話人數、字數、逾時與專屬 Prompt。AI 不可用時繼續普通儀式。請依 RimTalk 與 Expand Memory 各自的前置需求安裝，並將本模組排在它們之後。

## 實測與使用說明

已完成真實 API、完整存讀檔、自訂種族、大量模組環境與講述者面向人群的實際測試，運作正常。

RimTalk 內建對話歷史由本體管理，重啟後沒有可用紀錄屬正常行為。沒有記憶時改聊當下；AI 內容與字數依模型而定。
