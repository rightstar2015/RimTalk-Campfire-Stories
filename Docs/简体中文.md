## 需求 Mod

不使用以下模组也能进行此文化仪式，但是没有我当初想呈现的效果。

- [RimTalk](https://steamcommunity.com/workshop/filedetails/?id=3551203752)：启用这个模组才能实现“上台 → 演讲”的完整对话环节，沿用本体的模型及 API 设置。
- [RimTalk - Expand Memory](https://steamcommunity.com/sharedfiles/filedetails/?id=3608181242)：启用之后就能抽取讲述者自己的随机记忆。

## 篝火的故事

让 1～3 名殖民者围坐原生篝火，轮流面向人群，分享生活中的片刻。日常、战斗、人际与纪念都能成为话题。

基本需求为 RimWorld 1.6 和 Ideology。没有 RimTalk 时仍可完成普通文化仪式及获得一般仪式结果；安装 RimTalk 后会生成文字对话，仅有本体时使用讲述者自己的内置对话历史，同时安装 Expand Memory 时改用扩展记忆。无需再次输入 API Key，不增加特殊互动或主动记忆写回。

## 使用方式

1. 在文化中添加“战功歌”，建造并点燃原生篝火。
2. 选择参与者，指定最多三位讲述者；留空则自动选择 1～3 人。
3. 开始仪式，讲述者轮流上前并面向听众。AI 可用时由讲述者开场、听众接话，再简短收尾。

设置可调整讲述者人数、接话人数、字数、超时及专属 Prompt。AI 不可用时继续普通仪式。请按 RimTalk 和 Expand Memory 各自的前置需求安装，并将本模组排在它们之后。

## 实测与使用说明

已完成真实 API、完整存读档、自定义种族、大量模组环境及讲述者面向人群的实际测试，运行正常。

RimTalk 内置对话历史由本体管理，重启后没有可用记录属于正常行为。没有记忆时改聊当下；AI 内容及字数由模型决定。
