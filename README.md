# RimTalk - Campfire Stories

A RimWorld 1.6 Ideology ritual with one to three storytellers around a native campfire. Optional RimTalk dialogue and personal Expand Memory integration. Uses RimTalk's provider and API configuration.

## Installation

Requires RimWorld 1.6 and Ideology. Install RimTalk and its prerequisites for generated speeches; add RimTalk - Expand Memory for random personal expanded memories. Load this addon after these optional integrations. Place this folder in RimWorld/Mods, enable it, and add the war song ritual to your ideology. Do not enable local and Workshop copies together.
